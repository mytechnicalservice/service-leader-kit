# Eigene Regeln: Vertrieb

Regeln nur für Vertrieb (Angebote, Verträge, Key Accounts). Vertrieb liest diese Datei vor jeder Arbeit. Regeln für alle Agenten
stehen in `lernpunkte.md`; widerspricht eine Regel hier einem Lernpunkt, gilt die Regel hier.

Du kannst Regeln selbst eintragen oder sagen: „Merk dir: Vertrieb soll …“. Dann trägt der System-Architekt sie hier
ein. Keine Regel hebt die Schutzregeln auf: Das Kit sendet nichts, löscht nichts und wertet keine einzelnen
Mitarbeitenden aus.
